# 多租户文档编写指南

本工程同一套文档会同时服务多个品牌（租户）。撰写时只需在文件里加一两行声明，系统会根据访问网址自动切换显示内容。本文档列出全部写法，按"从粗到细"的顺序选用即可。

## 1. 当前租户

<!-- prettier-ignore -->
| 租户标识 | 代表品牌 | 本地预览地址 |
| --- | --- | --- |
| `default` | elepay | http://docs.stg.elepay.localhost:3000/ |
| `smcc` | stera smart one | http://docs-smcc.stg.elepay.localhost:3000/ |

- 网址中带 `smcc` → smcc 租户；其他 → default 租户。
- 未在文件里做任何声明的内容 = 所有租户都能看到（这是默认）。

## 2. 三种控制粒度

按需要选择，**粒度越小越精细**：

<!-- prettier-ignore -->
| 想做的事 | 用哪种写法 | 控制范围 |
| --- | --- | --- |
| 让某一**整篇文档**只在某租户出现 | 文档顶部 frontmatter | 整页 + 侧边导航 |
| 让某一**整个目录**只在某租户出现 | 目录里的 `meta.json` | 文件夹及其全部子页 |
| 在同一篇文档里**段落级**做差异 | 文档正文里的标签 | 任意区块、单个词、单张图 |

### 2.1 整页可见性（frontmatter）

在 `.mdx` / `.md` 文件最顶部的 `---` 区块加 `visibleOnTenant`：

```yaml
---
title: アカウント管理マニュアル
visibleOnTenant:
  - smcc
---
```

- 只允许列出的租户访问；其他租户既看不到侧边栏入口，也不能通过 URL 直接打开。
- 想让多个租户都看到，就把它们都列进去；想让所有租户都看到，**直接删掉这一节**（不要写空数组）。
- 真实例子：`content/docs/smcc/guide/account-management-manual.mdx`。

### 2.2 整个目录可见性（meta.json）

在某目录的 `meta.json`（或 `meta.en.json` / `meta.zh.json`）里加同一个字段：

```json
{
  "title": "端末アプリの設定",
  "visibleOnTenant": ["smcc"],
  "pages": ["regarding-the-device-binding", "wait-settings"]
}
```

- 该字段一旦写在父目录上，子页面默认继承父目录的可见性。
- 单个子页若再写 frontmatter `visibleOnTenant`，**子页的声明优先**。
- 多语言的 `meta.*.json` 各自独立，建议同步维护，避免某种语言下菜单顺序错乱。

### 2.3 段落级差异化（正文里的三种标签）

下面三种标签直接写在 `.mdx` 正文中即可，由系统按当前租户自动渲染。

#### EContainer — 只给指定租户看一段内容

```mdx
<EContainer tenant="smcc">
  这段话只有访问 stera smart one 站点时才会显示。
</EContainer>

<EContainer tenant="smcc,default">
  逗号分隔可以同时指定多个租户。
</EContainer>
```

- 内部可以放任意 Markdown：标题、列表、表格、图片、卡片都可以。
- `tenant` 不写或写空 = 所有租户可见。

#### EText — 把品牌名/网址等差异文案变成"占位符"

正文中写一次占位符，系统会替换成当前租户对应的文案。当前可用占位符：

| 占位符 name | default 显示 | smcc 显示 |
| --- | --- | --- |
| `elepay` | elepay | stera smart one |
| `dashboard_url` | https://dashboard.elepay.io/ | https://dashboard.sterasmartone.com/ |

写法：

```mdx
<EText name="elepay" /> の API は REST ベースで構成されています。

[<EText name="elepay" />管理画面](<EText name="dashboard_url" />)からログインしてください。
```

EText 的位置限制（**不能放进以下场景**，否则不会被替换）：

- 标题行：`## <EText name="elepay" />` ✗
- 行内反引号：`` `<EText name="elepay" />` `` ✗
- 围栏代码块（```` ``` ````）内部 ✗

可以放进的场景：

- 普通段落、加粗、引用、列表、表格单元格、链接文本与链接地址。

> 需要新增占位符？联系开发同学，他们会在租户配置里加一条键值。

#### EImg — 不同租户展示不同图片

同一张图位置，按租户切换素材：

```mdx
<EImg src="image.get-started.refunds.img1" alt="返金画面" />
```

当前可用图片键值（一律是已注册好的键，**不是文件路径**）：

<!-- prettier-ignore -->
| 键值 src | 用途 |
| --- | --- |
| `image.get-started.index.img` | 入门页主图 |
| `image.get-started.charge.img` | 入门 - 课金示意图 |
| `image.get-started.refunds.img1` / `image.get-started.refunds.img2` | 入门 - 返金示意图 |
| `image.server.webhook.img1` / `image.server.webhook.img2` | 服务端 Webhook 截图 |
| `image.sdks.url-scheme.img1` / `img2` / `img3` | URL Scheme 截图 |

> 需要新增图片或替换素材？把两套图（default 与 smcc 各一张）交给开发同学，由他们登记新的键值。

## 3. 优先级与默认值

- 同一页面同时存在多种声明时，优先级从高到低：
  1. 页面自身的 frontmatter `visibleOnTenant`
  2. 所在目录的 `meta.json` `visibleOnTenant`（最近的父级优先）
  3. 未声明 → 所有租户可见
- 空数组 `[]` 也视为"所有租户可见"。**真要做白名单，请写出具体租户键，不要留空。**
- 系统会自动同步处理这些场景，无需另外配置：
  - 不可见页面在侧边栏隐藏。
  - 不可见页面被前/后翻页跳过，避免点出死链。
  - 直接输入 URL 也无法访问被隐藏的页面。

## 4. 多语言与租户的关系

文件名约定（不变）：默认日语 `xxx.mdx`、英文 `xxx.en.mdx`、中文 `xxx.zh.mdx`。

注意点：

- 租户可见性**不会区分语言**：在日语版上声明 `visibleOnTenant: [smcc]`，并不会自动同步到英文版与中文版。请在每个语言版本里都写一次相同声明，保持一致。
- 目录的 `meta.json` / `meta.en.json` / `meta.zh.json` 各自独立。建议三份一起改。
- `<EText>` / `<EImg>` / `<EContainer>` 与语言无关，任何语言版本都可使用。

## 5. 写作流程速查

新建/编辑一篇仅供某租户的文档：

1. 在文件顶部加 `visibleOnTenant: [smcc]`（或 `[default]`）。
2. 同步检查所属目录的 `meta.json` 是否需要把该文件加入 `pages`。
3. 同语言的英中日版本都各加一份相同声明。
4. 本地访问对应租户的预览网址检查效果。

在通用文档里穿插租户差异：

1. 品牌名/网址 → 用 `<EText name="..." />` 替换硬编码文案。
2. 截图差异 → 用 `<EImg src="..." />` 引用统一键值。
3. 整段差异 → 用 `<EContainer tenant="...">...</EContainer>` 包裹。
4. 用两个预览网址各打开一遍，确认两套租户视图都对。

## 6. 常见坑

- **写了 `visibleOnTenant` 但页面还在所有租户显示**：检查是不是写成了空数组、或拼错了租户键（只能是 `smcc` / `default`，全小写）。
- **侧边栏看不到新建的页面**：除了 frontmatter，还要把文件加入同目录 `meta.json` 的 `pages`。
- **`<EText>` 没替换**：多半是写进了标题、反引号或代码块。挪到正文里即可。
- **导航在某租户下出现孤立分隔符**：把分隔符下方的全部页面都隐藏后，分隔符会自动清理，不必手动处理；若仍异常，检查 `meta.json` 的 `pages` 列表中是否有不存在的条目。
- **链接被翻页跳过**：这是正常行为——前后翻页只链向当前租户可见的页面，避免死链。
- **想给某段加"仅日语版可见"**：本工程**没有**按语言隐藏内容的语法。需要差异时请直接在对应语言文件里写不同的内容。

## 7. 名词对照

<!-- prettier-ignore -->
| 名词 | 含义 |
| --- | --- |
| 租户 / tenant | 同一套文档下区分的品牌站点，目前为 `default` 与 `smcc` |
| frontmatter | `.mdx` 文件顶部用 `---` 包起来的声明区 |
| meta.json | 控制目录顺序、标题、可见性等的配置文件 |
| 可见性 | 页面/目录在某租户下是否出现在导航与可访问 URL 中 |
| 占位符 | 文档里写一次、按租户自动替换为对应文案/图片的标签 |
