1. AllValue の管理画面にログインして、「設定」→「入金」をクリックしてください。

![](https://files.readme.io/413149c-pasted-image.png "pasted-image.png")

2. 入金画面の「その他の決済方法」項目→「支払い方法を選択」リンクをクリックしてください。

![](https://files.readme.io/f17adfb-pasted-image-2.png "pasted-image-2.png")

3. 決済サービスプロバイダー一覧から、「elepay」をクリックしてください。

![](https://files.readme.io/f71a6fc-pasted-image-3.png "pasted-image-3.png")

4. stera smart oneの設定画面に、App ID と Secret をご入力ください（設定値は stera smart one サポートデスクまでお問い合わせください）。

![](https://files.readme.io/4de8650-pasted-image-4.png "pasted-image-4.png")

5. ユーザーが選択できる決済方法を指定してください。指定が完了しましたら、「保存」ボタンをクリックしてください。

![](https://files.readme.io/c94d8d3-pasted-image-5.png "pasted-image-5.png")

6. 入金画面に戻りましたら、「レジの設定」にて決済方法の表示順を調整することができます。

![](https://files.readme.io/920b7ae-pasted-image-6.png "pasted-image-6.png")
