[stera smart one 管理画面](https://dashboard.sterasmartone.com)からログインしてください。

ログイン後、**「決済モジュール」→「開発設定」→「アプリ設定」**&#x306E;順番でお進みください（以下の画像をご参照ください）。

![](https://files.readme.io/b69d62b0b5bd8b6665c989e58c27402a2e6769265e4fdd0b6cf052abe9888dd1-_2024-11-19_15.46.08.png)

アプリ設定画面にて、アプリの設定を新規追加してください。追加する際に本番アプリのBundle ID（iOSアプリの場合）とPackage Name（Androidアプリの場合）が必要になります。

![](https://files.readme.io/6f926d25024c30f5cf6b066c93a1b512e0ccb7a76c32744099efcf5ab89f8415-_2024-11-19_15.48.58.png)

アプリの設定を追加しましたら、画面上に「導入ガイド」が表示され、URL Schemeがご確認できます。

![](https://files.readme.io/44e9cb8a8458adedaac3029dcfb4c787574fbf4bbf0dff154c62f24286351524-_2024-11-19_15.48.58.png)
