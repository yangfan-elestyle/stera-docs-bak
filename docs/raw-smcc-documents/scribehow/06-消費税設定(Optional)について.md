# 消費税設定(Optional)について

商品やサービスの税率、及び適格請求書発行事業者の登録番号はこちらで簡単に設定できます。
新しい商品を追加する際、あらかじめに設定したデフォルト税率が自動的に適用されます。
「税率適用」で「自動適用」を選択すると、通常の商品は標準税率、テイクアウト商品は軽減税率がそれぞれ適用されます。

Alert: 当システムでは、ユーザー向けの表示価格は税込みとして表現されます。外税設定に関しても、最終的には税抜き価格を基にした税込価格として表示されます。

税込み価格の算出は、指定した税率や端数処理方法を基に計算されます。端数処理の結果として、商品の最終価格（税込）と管理画面での設定価格には差異が出る場合がございます。この点を設定や価格設定の際にご確認いただくよう、ご注意ください。


#### 加盟店側設定方法


1\. Marketplaceをクリックしてください。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-11-13/c4d33edb-b46b-4fbb-99d6-c6f8032252cf/user_cropped_screenshot_6045c61ce3894ddea6d70a46d36af8c5_text_export.jpeg)


2\. 「消費税設定」をインストールしてください。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-04-25/4b75413d-12cb-4b3c-8e5c-f5a3fea2a7ec/ascreenshot_1871aa6a1eb94bf5b7b130c9646b9bc8_text_export.jpeg)


3\. 税金設定をしてください。

小売や飲食業界以外での利用の場合、税込価格は標準税率10%で自動設定されます。そのため、税タイプや適用税率、端数処理などの追加設定は不要です。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-05-17/0282de7a-5d79-4220-a7b1-5bb0e674729b/user_cropped_screenshot_a459c508af1c44f29aba07f0d4a17fc0_text_export.jpeg)


4\. 「適用税率」と「端数処理」を選択肢から指定してください。

「適用税率」で「自動適用」を選択すると、商品のデフォルト税率は標準税率、テイクアウトは軽減税率が自動的に設定されます。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-04-25/86ed9e23-a382-4399-b955-9a7f7203265a/ascreenshot_24e9fc79ced24479b99005ada374e982_text_export.jpeg)


5\. 適格請求書発行の事業者番号を設定してください。

的確請求書発行事業者番号を登録しますと、レシートや領収書に表示されます。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-04-25/6615e1f3-f3bc-41ca-8893-599cf79876e9/ascreenshot_fc953d08bd0843eda246e9107086b1fd_text_export.jpeg)


6\. 「保存」をクリックし、設定完了します。

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2024-04-25/5b929ee3-b49f-4ef9-ad29-2de3bc916945/ascreenshot_4347f5540c584df8aa849b44257c2067_text_export.jpeg)


#### ユーザー側表示イメージ


7\. ①適格請求書発行事業者の名称と登録番号

②取引年月日：取引した年月日が表示されます。

③取引内容（軽減税率の対象品目である旨）

軽減税率の対象商品には※が表示されます。

※軽減税率対象商品のみを販売した場合も、※が表示されます

④税率ごとの対象金額と消費税額

税率ごとの対象金額が表示されます。
