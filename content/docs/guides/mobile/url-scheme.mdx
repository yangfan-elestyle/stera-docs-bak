# iOS / Android SDK用URL Schemeの取得

[<EText name="elepay" />管理画面](https://dashboard.elepay.io/)からログインしてください。

ログイン後、**「マルチ決済」→「開発設定」→「アプリ設定」**の順番でお進みください（以下の画像をご参照ください）。

<EImg src="image.sdks.url-scheme.img1" />

アプリ設定画面にて、アプリの設定を新規追加してください。追加する際に本番アプリのBundle ID（iOSアプリの場合）とPackage Name（Androidアプリの場合）が必要になります。

<EImg src="image.sdks.url-scheme.img2" />

アプリの設定を追加しましたら、画面上に「導入ガイド」が表示され、URL Schemeがご確認できます。

<EImg src="image.sdks.url-scheme.img3" />
