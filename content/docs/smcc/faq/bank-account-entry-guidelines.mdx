申込フォームよりご入力いただく口座名義について、 ご利用可能な文字は下記の通りです

正しい「口座名義」をご確認のうえ、「口座名義（カタカナ）」へご入力ください

| 種類                | 使用可能な文字                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| カタカナ（全角）    | アイウエオ　カキクケコ　サシスセソ　タチツテト　ナニヌネノ<br></br>ハヒフヘホ　マミムメモ　ヤユヨ　ラリルレロ　ワヲン      |
| カナ+濁点（全角）   | ガギグゲゴ　ザジズゼゾ　ダヂヅデド　バビブベボ　ヴ                                                                         |
| カナ+半濁点（全角） | パピプペポ                                                                                                                 |
| 数字（全角）        | ０１２３４５６７８９                                                                                                       |
| 英字（全角大文字）  | ＡＢＣＤＥＦＧＨＩＪＫＬＭＮＯＰＱＲＳＴＵＶＷＸＹＺ                                                                       |
| 記号（全角）        | ，　．　－　／　「　」　（　）　￥<br></br>カンマ、ピリオド、ハイフン、スラッシュ、カギカッコ、<br></br>丸カッコ、円マーク |
| スペース（全角）    | 全角スペースをご入力ください                                                                                               |

> ❗️ 注意
>
> - 全角でご入力ください
> - 全角30文字までご入力いただけます（濁点・半濁点も1文字として数えます）
> - 漢字はご利用いただけません
> - 中黒点（・）はご利用いただけません  
>   中黒点（・）がある場合、ピリオド（．）に置き換えてご入力ください

また、ご利用可能となる略称は下記の通りです  
入力例）  
〇〇株式会社　　　　　　→　〇〇（カ  
株式会社〇〇　　　　　　→　カ）〇〇  
〇〇株式会社 東京営業所   →　〇〇（カ）トウキョウ（エイ
