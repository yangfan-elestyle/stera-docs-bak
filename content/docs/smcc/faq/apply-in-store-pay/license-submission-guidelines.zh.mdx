---
title: 提交许可证件的注意事项
---

如申请的业务类别需要许可／证照，必须提交相应的许可证件。请事先备齐所需材料。

在需提交许可／证照的业务类别下申请时，我们将要求提供相关许可的详细信息；请准备好必要的证件（如营业许可、古物商许可、开设届出済证明书、旅行业登记证、资格认定证、认证／登记编号、都道府县的许可编号等）。

### 所需许可／证照示例

- 营业许可
- 古物商许可
- 开设届出済证明书
- 旅行业登记证
- 资格认定证
- 认证／登记编号
- 都道府县许可编号等

### 需要许可等的业务类别示例（仅适用对象）

| 适用业种／经营商品                               | 所需资料                                                                                                                   |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 经营二手、回收用品或古物                         | 古物商许可                                                                                                                 |
| 属于施术所（针灸院、治疗院、接骨院／整骨院等）   | 开设届出済证明书                                                                                                           |
| 属于旅行代理                                     | 旅行业登记证                                                                                                               |
| 提供医疗咨询、法律咨询                           | 资格认定证／登记证（如社会福祉登记证、精神保健福祉登记证、律师身分证明等）                                               |
| 汽车驾驶代行业                                   | 汽车驾驶代行业认定证                                                                                                       |
| 属于“特定持续性劳务”※1                          | 法人：决算书（最近 3 期）／个人：蓝色申报（最近 3 期决算书）+ 确定申告书复印件                                            |
| 属于彩票／公营竞赛                               | 主办方出具的销售委托合同复印件※2                                                                                          |
| 属于保险业（保险代理店）                         | 代理店委托合同，或 2 名从业者的保险募集人资格登记证／合格证                                                                |
| 属于演出门票销售                                 | 古物商许可（二次销售时）／遵守《禁止不正倒卖门票法》的同意书※3                                                             |
| 属于礼品券、预付卡、交通乘车券销售               | 古物商许可（二次销售时）                                                                                                   |

※1 特定持续性劳务：补习班／家庭教师／语言学校／美容（エステ）／医美／电脑培训／婚介服务等。  
※2 非主办方的场合需提供。  
※3 受理申请后，我们将另行提供公司规定格式。

### 受限制的业种与店铺

以下业种不接受申请：

- 非法销售店
- 风俗业／成人娱乐业
- 赌博相关行业
- 我司判断为不适当的其他行业

详情请参阅《使用条款》与《指南》。
