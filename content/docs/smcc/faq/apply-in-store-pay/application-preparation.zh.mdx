申请所需材料在个体工商户与法人之间有所不同。

#### 个体工商户

以下身份证明二选一：

- 驾驶证或驾驶经历证明书
- 在留卡或特别永住者证明书
- 个人号码卡（My Number 卡）
- 各类健康保险证

申请表中填写的姓名与出生日期必须与身份证件一致。

以下店铺照片各 1 张：

- 店铺外观照片（请拍摄全景，确保店名招牌与入口清晰可见）
- 店铺内景照片（请拍摄全景，以便呈现所提供的服务及所售商品）

#### 法人

- 法人编号（设立登记时核发的 13 位编号）
  - 可在日本国税厅“法人编号公示网站”查询。

以下为经办人的身份证明（二选一，限申请信用卡支付时）：

- 驾驶证或驾驶经历证明书
- 在留卡或特别永住者证明书
- 个人号码卡（My Number 卡）
- 各类健康保险证

以下店铺照片各 1 张：

- 店铺外观照片（请拍摄全景，确保店名招牌与入口清晰可见）
- 店铺内景照片（请拍摄全景，以便呈现所提供的服务及所售商品）

| 适用业种／经营商品                               | 所需资料                                                                                             |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 经营二手、回收用品或古物                         | 古物商许可（线上经营的场合，另需提交 URL 备案）                                                      |
| 属于施术所（针灸院、治疗院、接骨院／整骨院等）   | 开设届出済证明书                                                                                     |
| 属于旅行代理                                     | 依据《旅行业法》的登记证或旅行业者代理业登记票                                                       |
| 提供医疗咨询、法律咨询                           | 资格认定证／登记证（如社会福祉登记证、精神保健福祉登记证、律师身分证明等）                           |
| 汽车驾驶代行业                                   | 汽车驾驶代行业认定证                                                                                 |
| 属于“特定持续性劳务”※1                          | 决算书（最近 3 个会计年度）                                                                          |
| 属于彩票／公营竞赛                               | 主办方出具的销售委托合同复印件※2                                                                    |
| 属于保险业（保险代理店）                         | 代理店委托合同，或 2 名从业者的保险募集人资格登记证／合格证                                          |
| 属于不动产中介                                   | 宅地建物取引士资格，或公司登记簿誊本（履历事项全部证明书）                                           |
| 属于演出门票销售                                 | 古物商许可（二次销售时）／遵守《禁止不正倒卖门票法》的同意书※3                                       |
| 属于礼品券、预付卡、交通乘车券销售               | 古物商许可（二次销售时）                                                                             |
| 法律事务所／律师事务所                           | 日本律师联合会核发的身分证明证件                                                                     |
| 自治体                                           | 与地方公共团体岁入相关的协定书（PayPay）                                                             |

※1 特定持续性劳务：补习班／家庭教师／语言学校／美容（エステ）／医美／电脑培训／婚介服务等。  
※2 非主办方的场合需提供。  
※3 受理申请后，我们将另行提供公司规定格式。  
※除上述以外的业种，如法律要求资格或许可，我们可能在申请后追加索取资料，敬请理解。
