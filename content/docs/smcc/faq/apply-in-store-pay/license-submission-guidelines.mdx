許可証等が必要な業種でのお申し込みの場合、該当の許可証をご提出いただく必要があります。必要な許可書をご用意ください。

許可証等が必要な業種でのお申し込みの場合は、許可証等の内容をご提出いただきますので、お手元に許可書（営業許可証、古物商許可証、開設届出済証明書、旅行業登録票、資格認定証、認定証番号、都道府県の認可番号、等々）などをご用意ください。

### 必要な許可書の例

- 営業許可証
- 古物商許可証
- 開設届出済証明書
- 旅行業登録票
- 資格認定証
- 認定証番号
- 都道府県の認可番号など

### 許可証等が必要な業種の例（該当の方のみ）

| 該当業種／取り扱い商品                           | 必要書類                                                                       |
| ------------------------------------------------ | ------------------------------------------------------------------------------ |
| 中古品、リサイクル品、古物の取り扱いがある       | 古物商許可証                                                                   |
| 施術所に該当（鍼灸院、治療院、接骨院・整骨院）   | 開設届出済証明書                                                               |
| 旅行代理店に該当                                 | 旅行業登録票                                                                   |
| 医療相談、法律相談を行なっている                 | 資格認定証／登録証（社会福祉登録証、精神保健福祉登録証、弁護士身分証明書など） |
| 運行代行業                                       | 自動車運転代行業認定証                                                         |
| 特定継続的役務に該当※1                           | 法人：決算書（3期分）／個人：青色申告書（決算書3期分）+確定申告書の写し        |
| 宝くじ／公営競技に該当                           | 主催者からの販売委託契約書の写し※2                                             |
| 保険業（保険代理店）に該当                       | 代理店委託契約書または2名分の保険募集人資格登録証／合格証                      |
| 興行チケット販売業に該当                         | 古物商許可証（二次販売の場合）／チケット不正転売禁止法遵守の同意書※3           |
| 商品券・プリペイドカード・交通乗車券販売業に該当 | 古物商許可証（二次販売の場合）                                                 |

※1 特定継続的役務：学習塾/家庭教師/語学教室/エステティック/美容医療/パソコン教室/結婚相手紹介サービスなど  
※2 主催者で無い場合は必要。  
※3 お申し込み受付後に別途弊社所定のフォーマットをご連絡いたします。

### 特定制限の業種や店舗

以下の業種は申し込みを受け付けておりません。

- 違法販売店
- 風俗業
- ギャンブル関連業
- 当社が不適当と判断した他の業種

詳細については、利用規約とガイドラインをご覧ください。
