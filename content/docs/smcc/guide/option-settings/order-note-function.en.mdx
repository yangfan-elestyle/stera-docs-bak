---
title: About the Order Note Feature
---

The order note feature allows customers to add free‑form requests when placing an order.<br />
(For example, specific allergy information, ingredient changes, or timing of item delivery.)<br />
This information is sent to the store together with the order details.

## Merchant‑side settings for order notes

### 1. Click Marketplace.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-11-13/8017b893-53e0-4f5e-87aa-864fe6594ffc/user_cropped_screenshot.jpeg?tl_px=0,0&br_px=2752,1380&force_format=jpeg&q=100&width=1120.0)

### 2. Click to install "Order note".

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/fa589819-de6a-4b6c-8e33-b6a8a3e0d4dd/ascreenshot.jpeg?tl_px=1220,167&br_px=2940,1128&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=708,277)

### 3. Configure the settings on this screen.

・Set as required: If enabled, customers must fill in the note field before confirming the order. Useful when specific information is mandatory.

・Multi‑line input: Provides a multi‑line text area instead of a single‑line field, allowing customers to enter more information.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-05-17/c324dad4-fd4e-4fb3-b4f2-0b868ef6fa5d/user_cropped_screenshot.jpeg?tl_px=41,0&br_px=2334,1281&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=524,275)

### 4. Configure the label and placeholder (the faint text shown before input), and the maximum input length displayed to customers.

・Label example: "Requests for the order"

・Placeholder example: "Please enter allergy information or any requests related to the order"

・Max input length: Restrict the maximum number of characters if necessary.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/805d25b1-193d-4164-a4e4-c783b56d26bf/ascreenshot.jpeg?tl_px=634,141&br_px=2354,1102&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=524,276)

### 5. Click "Save" to complete the store‑side configuration.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/5dfca674-b3e0-4a5c-9859-93499e2d6db8/ascreenshot.jpeg?tl_px=440,580&br_px=2160,1542&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=524,509)

## User‑side input for order notes

### 6. Click "Pay" at the bottom right.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/07090de8-b4e9-459b-b067-9f328bc890f0/user_cropped_screenshot.jpeg?tl_px=26,0&br_px=1173,635&force_format=jpeg&q=100&width=1120.0)

### 7. Enter any special notes in the order note field.

Information entered by customers is available to the store together with the order details.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/e8c961fa-bbf5-4ae8-a23a-75b3c2f728ac/user_cropped_screenshot.jpeg?tl_px=168,76&br_px=1028,556&force_format=jpeg&q=100&width=860)
