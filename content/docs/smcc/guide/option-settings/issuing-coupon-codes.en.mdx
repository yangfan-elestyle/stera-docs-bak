title: About Issuing Coupon Codes
---

Issuing coupon codes is an efficient promotion method for store administrators. There are three issuance methods:<br />
① Use a specified code<br />
② CSV method<br />
③ Auto‑generate codes

## Coupon settings for store administrators

### 1. Click "Coupons" to open the management page.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/b75f9e5a-471a-4a71-9ded-cd94c927f358/ascreenshot.jpeg?tl_px=0,487&br_px=1376,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=149,276)

### 2. Click "New" to create a coupon.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-05-17/5628f0fb-55b9-40a4-997f-85c9e03d688e/user_cropped_screenshot.jpeg?tl_px=0,0&br_px=1630,961&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=921,216)

### 3. Configure the "Coupon details" fields.

Acquisition type<br />
Code: Discount is applied by entering a code you configure on the checkout page<br />
No code required: Automatically applied at checkout<br />
Grant automatically after login: Granted after SaaS account login (for user administrators)<br />
Grant automatically after purchase: Granted after purchase by the account owner (for user administrators)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/32cc5a86-0170-45c3-be03-5156093cc20d/ascreenshot.jpeg?tl_px=0,167&br_px=1630,1128&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=609,294)

### 4. When the acquisition type is "Code", there are three ways to create codes.

① Coupon code type "Specified"<br />
You can set a company‑specified string as the coupon code.<br />
Set the code type to "Specified" and enter the required code in the coupon code field.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/3da4083a-2732-49d1-93a2-726b4f5d6abb/ascreenshot.jpeg?tl_px=0,293&br_px=1630,1254&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=581,294)

### 5. ② Coupon code type "CSV import"

You can upload a CSV file containing many company‑specified codes to register them in bulk.<br />
Select the code type "CSV import" and upload the CSV file prepared in advance.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/68b1bd0f-7565-49e7-9fc7-ac33ef494f5b/ascreenshot.jpeg?tl_px=0,47&br_px=1630,1008&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=656,294)

### 6. ③ Coupon code type "Auto‑generate"

If you do not require a specific code, the system can generate codes automatically.<br />
Select the code type "Auto‑generate" and the system will generate coupon codes at random.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/aa5d3fee-b9cd-447e-9545-bcbdb66f6e00/ascreenshot.jpeg?tl_px=0,49&br_px=1630,1010&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=805,294)

### 7. Configure the "Valid period" and "Issuable quantity".

※ Issuable quantity: 1\~1000

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/aa010382-f1c1-410c-82d1-95d42dec7246/ascreenshot.jpeg?tl_px=0,249&br_px=1630,1210&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=668,294)

### 8. After confirming all information, click "Save".

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-05-20/d59e2cba-6e9e-43a9-9b7f-69c13162fd01/user_cropped_screenshot.jpeg?tl_px=0,504&br_px=1630,1466&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=561,525)

### 9. Finally, click "Publish".

※ If target products are specified, orders must include a target product when using the coupon. The discount applies only to target products.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-05-20/9e8e6f96-525c-4547-b8fc-1e3dc88a710c/user_cropped_screenshot.jpeg?tl_px=0,504&br_px=1630,1466&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=693,535)

### 10. If you selected "Auto‑generate" as the code type, click the coupon again to download the generated codes.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-05-20/15c08383-4a5a-4efc-a84f-6415436c42e8/user_cropped_screenshot.jpeg?tl_px=0,399&br_px=1719,1360&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=104,277)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/350d9abc-413f-4784-a5d4-45cccb08eac5/ascreenshot.jpeg?tl_px=42,281&br_px=1762,1242&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=913,277)

## How users redeem coupons

### 14. Getting coupons

Record the promotion code distributed directly by the store or company.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/39d28435-5619-4fdf-a0b1-c27bb909cdd4/screenshot.webp?tl_px=26,0&br_px=1173,635&force_format=jpeg&q=100&width=1120.0)

### 15. Applying coupons

① On the website, select products or services and add them to the cart.

② On the cart or checkout page, enter the coupon code you obtained.

③ The coupon is applied and the discount amount is shown. Confirm the total amount after discount, then proceed to payment.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2024-04-25/8e08e9f1-ab25-4414-a251-b3dba828c244/screenshot.webp?tl_px=108,42&br_px=1091,591&force_format=jpeg&q=100&width=983)
