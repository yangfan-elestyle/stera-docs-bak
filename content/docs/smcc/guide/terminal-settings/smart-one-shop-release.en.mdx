This guide is intended for merchants using kiosk terminals.

Kiosk Mode displays a specific application full-screen and restricts access to other applications. This function prevents customers from accessing other apps while ordering.

Tip: Kiosk Mode displays a designated application full-screen and restricts access to other applications, making it suitable for terminals used in retail and public spaces.

Tip: For use of Kiosk Mode, a Sunmi partner configures the smart one Shop app to run in Kiosk Mode. After that configuration, when you launch the app on a device where it is installed, it switches to Kiosk Mode automatically.

## Steps to temporarily exit Kiosk Mode

### 1. Press and hold the device's power button.

![](/docs/99554166-screenshot.jpeg)

### 2. The Kiosk exit menu appears; tap the "Exit Kiosk" button at the top right.

![](/docs/9856b97c-screenshot.jpeg)

### 3. Enter the password (default: 1234) to exit Kiosk Mode.

![](/docs/4444d563-screenshot.jpeg)

Alert: When you launch an app that a Sunmi Partner configured to start in Kiosk Mode, the device returns to Kiosk Mode.
