---
title: 设备端 Checkout
---

将固定设备配置为可进行灵活的支付。

> - 接入工作量：低代码，约 40 分钟
> - 实现方式：在页面中嵌入二维码
> - UI 自由度：受限

由用户或门店员工操作设备并展示支付二维码的三步流程。

### 步骤 1：为商品/服务创建 EasyQR 码

### 步骤 2：设置嵌入式 UI 的样式并应用到设备

<EText name="elepay" /> 提供一定范围内的 UI 自定义能力，适用于通用场景。

| Param                         | Type      | Description                                   |
| ----------------------------- | --------- | --------------------------------------------- |
| options                       | `object`  | 小部件（Widget）选项                          |
| options.container             | `string`  | 目标容器 DOM 元素的 CSS 选择器字符串          |
| options.direction             | `string`  | 小部件布局：vertical（默认）或 horizontal     |
| options.icon                  | `boolean` | 为 true 时显示带品牌图标的二维码。默认：false |
| options.parts.amount          | `boolean` | 为 true 时显示金额。默认：true                |
| options.parts.paymentLogo     | `boolean` | 为 true 时显示支付方式图标。默认：true        |
| options.parts.tip             | `boolean` | 为 true 时显示帮助信息。默认：true            |
| options.theme.primaryColor    | `boolean` | 主色                                          |
| options.theme.borderColor     | `boolean` | 小部件边框颜色。null：无边框                  |
| options.theme.backgroundColor | `boolean` | 小部件背景色。默认：白色                      |

### 步骤 3：用户完成支付后，处理支付状态

Widget 提供用于检测支付进度的[事件](/sdks/javascript/api-reference)。

| 进度/状态  |                                                                                    |
| ---------- | ---------------------------------------------------------------------------------- |
| 支付成功   | `widget.on('success', function (event, codeObject) {// 支付完成后的处理  });`      |
| 支付已过期 | `widget.on('expired', function (event, codeObject) {// 例如生成新的 EasyQR 码 });` |
| 支付错误   | `widget.on('error', function (event, error) { // 错误处理  });`                    |
| 销毁小部件 | `widget.destroy();`                                                                |

### 其他设置

#### Checkout 页面 UI 自定义

用户看到的 Checkout 页面可在 <EText name="elepay" />「[簡単決済>設定>基本設定]」中调整图标与配色方案。

#### 支付方式设置

可在 <EText name="elepay" />「[簡単決済>設定>決済方法管理]」中管理可用的支付方式（查看、启用、禁用）。后续新增的支付方式也可立即使用。

#### 添加位置信息

创建 EasyQR 码时可附加位置信息，也可在 <EText name="elepay" />「[ロケーション]」中进行管理。
