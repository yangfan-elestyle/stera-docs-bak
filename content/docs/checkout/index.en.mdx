EasyCheckout is <EText name="elepay" />’s dynamic QR code (MPM) feature. It is used to dynamically display a QR code in the following scenarios so customers can scan and pay.

- E‑commerce websites
- Self‑ordering
- Checkout terminals
- Ticket vending machines
- Vending machines
