Elepay 是一个专注于移动端的多支付平台。它统一了复杂的移动支付流程，让您仅需一次开发即可支持主流移动支付方式。Elepay SDK 包含客户端 SDK 和服务端 SDK。客户端 SDK 支持 iOS、Android 与 HTML5，服务端 SDK 覆盖七种常用的后端开发语言。

# 特点

## 快速集成

- 统一的 SDK/API
- 面向开发者的友好体验
- 简洁高效的接入流程
- 优雅的 API 设计

## 一站式覆盖

一次开发即可覆盖主流移动支付方式，并将持续扩展对新支付方式的支持。

| 地区       | 可用支付品牌                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 日本       | PayPay、LINE Pay、楽天ペイ、au Pay、d 払い、Paidy、atone、AEON Pay                                                                                |
| 中国大陆   | Alipay、WeChat Pay、UnionPay、雲閃付                                                                                                                |
| 亚洲       | JKOPAY（台湾）、AlipayHK（香港）、KaKaoPay（韩国）、Touch'n Go（马来西亚）、GCash（菲律宾）、TrueMoney（泰国）、DANA（印度尼西亚）、Rabbit LINE Pay、Boost、BPI |
| 全球       | Apple Pay、Google Pay、Paypal、AmazonPay、信用卡（Visa、MasterCard、Amex、JCB、DinnersClub、Discover）                                              |

## 成本优势

- 提供具有竞争力的支付手续费方案。
- 帮助企业最大限度降低开发、部署与管理成本。
- 支持提供私有化 SaaS 方案。

# 适用场景

## 初创企业支持

在控制开发、运营与管理成本的同时快速上线服务。

## 电商服务

多元支付方式减少因支付选项不足导致的购买流失，推动线上销售增长。

## 入境旅游

支持 Alipay、WeChat Pay、银联、Apple Pay、Google Pay、Paypal 等常见海外支付方式，优化访日游客的消费体验。

## 共享经济

为共享单车、共享充电宝、共享停车等共享经济业务提供专业的移动支付解决方案。

## O2O 服务

通过二维码方案连接线上与线下，提升门店引流与转化效果。
