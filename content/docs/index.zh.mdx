elepay 是一款专注移动端的多合一支付平台。它将复杂的移动支付处理统一起来，单次集成即可支持主流移动支付方式。elepay SDK 包含 Client SDK 与 Server SDK。Client SDK 支持 iOS、Android 与 HTML5。Server SDK 支持 7 种后端开发语言。

![](/docs/47fd650d6c9c291daf95fb2bac603aa4b4ee6566d73a1e1d3acd796f447cdba4-image_42.png)

# 特性

## 简单集成

- 统一的 SDK/API
- 对开发者友好
- 集成简单且高效
- 优秀的 API 设计

## 一体化

单次开发即可支持主流移动支付方式。后续也将持续支持新的移动支付方式。

| 地区     | 可用支付品牌                                                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 日本     | PayPay、LINE Pay、楽天ペイ、au Pay、d 払い、Paidy、atone、AEON Pay                                                                                        |
| 中国大陆 | Alipay、WeChat Pay、UnionPay、雲閃付                                                                                                                      |
| 亚洲     | JKOPAY(台湾)、AlipayHK(香港)、KaKaoPay(韓国)、Touch'n Go(マレーシア)、GCash(フィリピン)、TrueMoney(タイ)、DANA(インドネシア)、Rabbit LINE Pay、Boost、BPI |
| 全球     | Apple Pay、Google Pay、Paypal、AmazonPay、クレジットカード (Visa、MasterCard、Amex、JCB、DinnersClub、Discover)                                           |

## 成本节约

- 提供优惠的支付费率方案。
- 将开发、集成与运营管理成本降至最低。
- 亦可提供私有化 SaaS 方案。

# 适用对象

## 初创支持

在尽量降低支付系统的开发、运维与管理成本的同时，即可开始使用服务。

## 电商服务

对于在互联网上进行商品买卖的电商服务方，可减少因支付方式不足带来的购买损失。

## 入境消费

支持海外常用的移动支付方式，如 Alipay、WechatPay、银联、Apple Pay、Google Pay、Paypal，有助于促进访日游客在日本境内的消费。

## 共享经济

为共享单车、共享电池、共享停车等共享经济服务提供最合适的支付解决方案。

## O2O 服务

提供将线上服务（Online）与线下门店（Offline）的拉新与转化连接起来的二维码解决方案。
