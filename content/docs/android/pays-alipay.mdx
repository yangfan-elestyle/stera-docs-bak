title: Alipay
---

アリペイを使うために、[アリペイの sdk](https://doc.open.alipay.com/doc2/detail.htm?treeId=54&articleId=104509&docType=1)をダウンロードし、プロジェクトの libs フォルダーに配置します。

> 📘 アリペイの sdk 名はこのような形になります。  
> alipaySdk-15.6.8-20191021122455-noUtdid.aar

そして、アプリの`build.gradle`に、アリペイ sdk の依存関係を追加します。

```groovy
dependencies {
  // ... other dependencies
  implementation files('libs/alipaySdk-20170725.jar')
}
```
