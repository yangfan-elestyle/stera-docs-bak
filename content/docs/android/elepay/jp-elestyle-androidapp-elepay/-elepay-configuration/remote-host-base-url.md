val [remoteHostBaseUrl](../remote-host-base-url): [String](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/index.html)

The url used as the base url when accessing remote resources/APIs.

You can pass in your own server's url to make the whole resources completely under your control. Normally, if you're using elepay's service, you should leave this parameter empty.
