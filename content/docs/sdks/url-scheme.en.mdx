# Obtain the URL Scheme for iOS / Android SDK

Please log in from the [elepay dashboard](https://dashboard.elepay.io/).

After logging in, go to **Multi-Payments → Developer Settings → App Settings** in this order (see the images below).

![](/docs/8ff36ca-IMG_0665.png)

On the App Settings screen, add a new app configuration. When adding, you will need the production app’s Bundle ID (for iOS apps) and Package Name (for Android apps).

![](/docs/bda4ad9-IMG_0666.png)

Once the app configuration is added, a “Getting Started” guide will be shown on the screen where you can confirm the URL Scheme.

![](/docs/62d3dac-IMG_0667.png)
