# 获取 iOS / Android SDK 的 URL Scheme

请从 [elepay 管理后台](https://dashboard.elepay.io/) 登录。

登录后，依次进入 **「多方式支付」→「开发设置」→「应用设置」**（请参考下方截图）。

![](/docs/8ff36ca-IMG_0665.png)

在应用设置页面新增一条应用配置。新增时需要提供生产应用的 Bundle ID（iOS 应用）与 Package Name（Android 应用）。

![](/docs/bda4ad9-IMG_0666.png)

添加完成后，页面会显示「导入指南」，其中可以查看到对应的 URL Scheme。

![](/docs/62d3dac-IMG_0667.png)
