title: 支付 Extra 信息设置
---

## 当支付资源为 `web`、`ios`、`android` 时

### Alipay+（Alipay、AlipayHK、KakaoPay、GCash、TNG 等）

| 项目          | 说明                 | 必填                  |
| ------------- | -------------------- | --------------------- |
| **frontUrl**  | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |
| **userAgent** | 浏览器 User‑Agent    | 当资源为 `web` 时必填 |

### Apple Pay

| 项目         | 说明                               | 必填 |
| ------------ | ---------------------------------- | ---- |
| **shopName** | Apple Pay 授权页面显示的收款方名称 | 可选 |

### Google Pay

| 项目         | 说明                                | 必填                             |
| ------------ | ----------------------------------- | -------------------------------- |
| **shopName** | Google Pay 授权页面显示的收款方名称 | 可选                             |
| **frontUrl** | 支付完成后的跳转 URL                | 当资源为 `web` 且启用 3DS 时必填 |

### atone

| 项目            | 说明                     | 必填 |
| --------------- | ------------------------ | ---- |
| **productName** | 在用户账单中显示的商品名 | 可选 |

### LINE Pay

| 项目                | 说明                            | 必填                            |
| ------------------- | ------------------------------- | ------------------------------- |
| **frontUrl**        | 支付完成后的跳转 URL            | 当资源为 `web` 或 `liff` 时必填 |
| **productName**     | LINE Pay 授权页面显示的商品名   | 可选                            |
| **productImageUrl** | LINE Pay 授权页面显示的商品图片 | 可选                            |

### 银联（UnionPay）

| 项目            | 说明                     | 必填                  |
| --------------- | ------------------------ | --------------------- |
| **frontUrl**    | 支付完成后的跳转 URL     | 当资源为 `web` 时必填 |
| **productName** | 银联授权页面显示的商品名 | 可选                  |

### au PAY

| 项目         | 说明                 | 必填                  |
| ------------ | -------------------- | --------------------- |
| **frontUrl** | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |

### Merpay（メルペイ）

| 项目         | 说明                 | 必填                  |
| ------------ | -------------------- | --------------------- |
| **frontUrl** | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |

### d 扫码支付（d払い）

| 项目         | 说明                 | 必填                  |
| ------------ | -------------------- | --------------------- |
| **frontUrl** | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |

### J‑Coin Pay

| 项目         | 说明                 | 必填                  |
| ------------ | -------------------- | --------------------- |
| **frontUrl** | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |

### PayPal

无需额外信息。

### Paidy

| 项目         | 说明                         | 必填 |
| ------------ | ---------------------------- | ---- |
| **shopName** | Paidy 授权页面显示的门店名称 | 可选 |

### PayPay

| 项目            | 说明                 | 必填                  |
| --------------- | -------------------- | --------------------- |
| **frontUrl**    | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |
| **productName** | 商品名               | 可选                  |

### 微信支付（WeChat Pay）

| 项目            | 说明                 | 必填                   |
| --------------- | -------------------- | ---------------------- |
| **frontUrl**    | 支付完成后的跳转 URL | 当资源为 `web` 时必填  |
| **productName** | 商品名               | 可选                   |
| **openid**      | 用户 openid          | 当资源为 `mini` 时必填 |

### 楽天支付（RPay）

| 项目          | 说明                 | 必填                  |
| ------------- | -------------------- | --------------------- |
| **frontUrl**  | 支付完成后的跳转 URL | 当资源为 `web` 时必填 |
| **userAgent** | 浏览器 User‑Agent    | 当资源为 `web` 时必填 |

### アトカラ（Atokara）

| 项目         | 说明                 | 必填 |
| ------------ | -------------------- | ---- |
| **frontUrl** | 支付完成后的跳转 URL | 必填 |
| **fullName** |                      | 必填 |
| **zipCode**  |                      | 必填 |
| **address**  |                      | 必填 |
| **tel**      |                      | 必填 |
| **email**    |                      | 必填 |

## 当支付资源为 `cpm` 时

### 通用字段

| 项目      | 说明                     | 必填 |
| --------- | ------------------------ | ---- |
| **token** | 扫描到的条码或二维码的值 | 必填 |

## 当支付资源为 `reader` 时

### 通用字段

| 项目         | 说明          | 必填 |
| ------------ | ------------- | ---- |
| **readerId** | 终端读卡器 ID | 必填 |

## Create EasyQR 场景

### 通用字段

| 项目                     | 说明                                                   | 必填 |
| ------------------------ | ------------------------------------------------------ | ---- |
| **defaultPaymentMethod** | 默认显示的支付品牌；用户可在界面上切换到其他支付方式。 | 可选 |

## 信用卡场景

| 项目                    | 说明                   | 必填                             |
| ----------------------- | ---------------------- | -------------------------------- |
| **requestThreeDSecure** | 设为 `true` 以启用 3DS | 可选                             |
| **frontUrl**            | 支付完成后的跳转 URL   | 当资源为 `web` 且启用 3DS 时必填 |
