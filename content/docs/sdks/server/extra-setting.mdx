## 決済リソースは `web`, `ios`, `android` の場合

### Alipay+ (Alipay, AlipayHK, KakaoPay, GCash, TNGなど)

| 項目          | 説明                | 必須                          |
| ------------- | ------------------- | ----------------------------- |
| **frontUrl**  | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |
| **userAgent** | ブラウザのUserAgent | 決済はwebの場合は必須         |

### Apple Pay

| 項目         | 説明                               | 必須 |
| ------------ | ---------------------------------- | ---- |
| **shopName** | ApplePay決済承認画面表示する支払先 | 任意 |

### Google Pay

| 項目         | 説明                                | 必須                                       |
| ------------ | ----------------------------------- | ------------------------------------------ |
| **shopName** | GooglaPay決済承認画面表示する支払先 | 任意                                       |
| **frontUrl** | 決済後に遷移するURL                 | 決済リソースはweb、且つ3DS認証の場合は必須 |

### atone

| 項目            | 説明                             | 必須 |
| --------------- | -------------------------------- | ---- |
| **productName** | ユーザー利用明細に表示する商品名 | 任意 |

### LINE Pay

| 項目                | 説明                                | 必須                                      |
| ------------------- | ----------------------------------- | ----------------------------------------- |
| **frontUrl**        | 決済後に遷移するURL                 | 決済リソースはwebあるいはliffの場合は必須 |
| **productName**     | LinePay決済承認画面表示する商品名   | 任意                                      |
| **productImageUrl** | LinePay決済承認画面表示する商品画像 | 任意                                      |

### 銀聯 (Union Pay)

| 項目            | 説明                           | 必須                          |
| --------------- | ------------------------------ | ----------------------------- |
| **frontUrl**    | 決済後に遷移するURL            | 決済リソースはwebの場合は必須 |
| **productName** | 銀聯決済承認画面表示する商品名 | 任意                          |

### au PAY

| 項目         | 説明                | 必須                          |
| ------------ | ------------------- | ----------------------------- |
| **frontUrl** | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |

### Merpay （メルペイ）

| 項目         | 説明                | 必須                          |
| ------------ | ------------------- | ----------------------------- |
| **frontUrl** | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |

### d払い

| 項目         | 説明                | 必須                          |
| ------------ | ------------------- | ----------------------------- |
| **frontUrl** | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |

### J-Coin Pay

| 項目         | 説明                | 必須                          |
| ------------ | ------------------- | ----------------------------- |
| **frontUrl** | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |

### PayPal

必要Extra情報がありません。

### Paidy

| 項目         | 説明                        | 必須 |
| ------------ | --------------------------- | ---- |
| **shopName** | Paidy承認画面表示する店舗名 | 任意 |

### PayPay

| 項目            | 説明                | 必須                          |
| --------------- | ------------------- | ----------------------------- |
| **frontUrl**    | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |
| **productName** | 商品名              | 任意                          |

### WeChat Pay

| 項目            | 説明                | 必須                           |
| --------------- | ------------------- | ------------------------------ |
| **frontUrl**    | 決済後に遷移するURL | 決済リソースはwebの場合は必須  |
| **productName** | 商品名              | 任意                           |
| **openid**      | ユーザのopenid      | 決済リソースはminiの場合は必須 |

### RPay（楽天ペイ）

| 項目          | 説明                | 必須                          |
| ------------- | ------------------- | ----------------------------- |
| **frontUrl**  | 決済後に遷移するURL | 決済リソースはwebの場合は必須 |
| **userAgent** | ブラウザのUserAgent | 決済リソースはwebの場合は必須 |

| ------------ | ------------------- | ---- |

## 決済リソースは `cpm` の場合

### 共通項目

| 項目      | 説明                                       | 必須 |
| --------- | ------------------------------------------ | ---- |
| **token** | スキャンしたバーコードあるいはQRコードの値 | 必須 |

## 決済リソースは `reader` の場合

### 共通項目

| 項目         | 説明                 | 必須 |
| ------------ | -------------------- | ---- |
| **readerId** | ターミナルリーダーID | 必須 |

## Create EasyQRの場合

### 共通項目

| 項目                     | 説明                                                                                               | 必須 |
| ------------------------ | -------------------------------------------------------------------------------------------------- | ---- |
| **defaultPaymentMethod** | デフォルトで表示したい決済ブランドを指定できます。ユーザーは他の決済方法に変更することが可能です。 | 任意 |

## クレジットカードの場合

| 項目                    | 説明                                              | 必須                                       |
| ----------------------- | ------------------------------------------------- | ------------------------------------------ |
| **requestThreeDSecure** | 「true」に設定すると3DSを利用することができます。 | 任意                                       |
| **frontUrl**            | 決済後に遷移するURL                               | 決済リソースはweb、且つ3DS認証の場合は必須 |

## 決済ステーション（コンビニ支払い）

| 項目         | 説明                     | 必須 |
| ------------ | ------------------------ | ---- |
| frontUrl     | 決済後に遷移するURL      | 必須 |
| fullName     | フルネーム               | 任意 |
| fullNameKana | フルネーム（カナ）       | 任意 |
| tel          | 電話番号                 | 任意 |
| email        | メールアドレス           | 任意 |
| expiryDate   | 支払い期限(: "yyyyMMdd") | 任意 |
| productName  | 購入商品 / サービス内容  | 任意 |

## 決済ステーション（銀行振込）

| email       | メールアドレス           | 任意 |
