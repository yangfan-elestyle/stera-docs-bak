# iOS App の Callback URL Scheme について

elepay デフォルト  *URL Scheme*  については、[こちら](https://developer.elepay.io/docs/ios-sdk#section-1-url-scheme-%E3%81%AE%E8%BF%BD%E5%8A%A0)をご参照ください。

それ以外にも、WeChat 専用の  *URL Scheme* （`wx`から始まるもの）が必要です。  
[「elepay 管理画面」](https://dashboard.elepay.io/) \> **開発設定** \> **アプリ設定**にある  **URL Scheme** \> **WeChat Pay**  項目を確認してください。なお、WeChat Pay が未開通の場合、該当項目は表示しません。

# iOS 9 及び以降のシステムについて

WeChat Pay アプリに遷移するために、Xcode の  **PROJECT** → **TARGETS**  にある  **Info**タグ（或いは  `Info.plist`）で、`LSApplicationQueriesSchemes` Key を追加してください。

```xml
<string>weixin</string>
<string>weixinULAPI</string>
```
