---
title: About installing smart one Shop
---

### 1. Open the App Store app on the home screen of the SUNMI K2 Mini or a generic device.

![](/docs/de458e83-screenshot.jpeg)

### 2. Tap the search button in the top right, search for "smart one Shop", then select "smart one Shop" from the results.

### 3. On the smart one Shop app detail page, tap Install in the lower right to install the app.

If already installed, "Open" is shown. Tap "Open" to launch the app.
