---
title: 申込にあたり、お店側で準備が必要なものはありますか？
---

お申込み時に必要なものについては、個人事業主様と法人様にて異なります。

#### 個人事業主の方

下記の本人確認書類のいずれか1点:

- 運転免許証または運転経歴証明書
- 在留カードおよび特別永住者証明書
- 個人番号カード（マイナンバーカード）
- 各種健康保険証

お申込みフォームにご記入いただいた氏名と生年月日が、本人確認書類と一致している必要がございます。

下記の店舗写真を1枚ずつ:

- 店舗外観画像（店舗名（看板等）と店舗の入り口がわかるように全景を撮影してください）
- 店舗内観画像（サービスの内容、お取り扱いの商材がわかるように全景を撮影してください）

#### 法人の方

- 法人番号（法人登録した際に発行された番号13桁）
  - ※法人番号は[国税庁法人番号公表サイト](https://www.houjin-bangou.nta.go.jp/)で検索できます。

下記ご担当者様の本人確認書類のいずれか1点（クレジットカード決済をお申し込みの方のみ）:

- 運転免許証または運転経歴証明書
- 在留カードおよび特別永住者証明書
- 個人番号カード（マイナンバーカード）
- 各種健康保険証

下記の店舗写真を1枚ずつ:

- 店舗外観画像（店舗名（看板等）と店舗の入り口がわかるように全景を撮影してください）
- 店舗内観画像（サービスの内容、お取り扱いの商材がわかるように全景を撮影してください）

| 該当業種／取り扱い商品                           | 必要書類                                                                       |
| ------------------------------------------------ | ------------------------------------------------------------------------------ |
| 中古品、リサイクル品、古物の取り扱いがある       | 古物商許可証（オンライン事業の場合、URL届出も必要）                            |
| 施術所に該当（鍼灸院、治療院、接骨院・整骨院）   | 開設届出済証明書                                                               |
| 旅行代理店に該当                                 | 旅行業法に基づく登録証または旅行業者代理業登録票                               |
| 医療相談、法律相談を行なっている                 | 資格認定証／登録証（社会福祉登録証、精神保健福祉登録証、弁護士身分証明書など） |
| 運行代行業                                       | 自動車運転代行業認定証                                                         |
| 特定継続的役務に該当※1                           | 決算書（3期分）                                                                |
| 宝くじ／公営競技に該当                           | 主催者からの販売委託契約書の写し※2                                             |
| 保険業（保険代理店）に該当                       | 代理店委託契約書または2名分の保険募集人資格登録証／合格証                      |
| 不動産仲介業に該当                               | 宅地建物取引士または履歴事項全部証明書                                         |
| 興行チケット販売業に該当                         | 古物商許可証（二次販売の場合）／チケット不正転売禁止法遵守の同意書※3           |
| 商品券・プリペイドカード・交通乗車券販売業に該当 | 古物商許可証（二次販売の場合）                                                 |
| 法律事務所・弁護士事務所                         | 日本弁護士連合会発行の身分証明書                                               |
| 自治体                                           | 地方公共団体の歳入にかかる協定書（PayPay）                                     |

※1.特定継続的役務：学習塾/家庭教師/語学教室/エステティック/美容医療/パソコン教室/結婚相手紹介サービスなど  
※2.主催者で無い場合は必要。  
※3.お申し込み受付後に別途弊社所定のフォーマットをご連絡いたします。  
※上記以外の業種においては、法律で資格が必須とされている場合があります。お申込み後、弊社から追加資料の要求がある場合もございますので、あらかじめご了承ください。
