---
title: What characters can be entered for the account holder name?
---

For the account holder name you enter in the application form, the characters you can use are as follows

After confirming the correct "Account holder name", please enter it in "Account holder name（Katakana）"

| Type                            | Allowed characters                                                                                                      |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Katakana（full-width）          | アイウエオ　カキクケコ　サシスセソ　タチツテト　ナニヌネノ<br></br>ハヒフヘホ　マミムメモ　ヤユヨ　ラリルレロ　ワヲン   |
| Kana + dakuten（full-width）    | ガギグゲゴ　ザジズゼゾ　ダヂヅデド　バビブベボ　ヴ                                                                      |
| Kana + handakuten（full-width） | パピプペポ                                                                                                              |
| Numbers（full-width）           | ０１２３４５６７８９                                                                                                    |
| Letters（full-width uppercase） | ＡＢＣＤＥＦＧＨＩＪＫＬＭＮＯＰＱＲＳＴＵＶＷＸＹＺ                                                                    |
| Symbols（full-width）           | ，　．　－　／　「　」　（　）　￥<br></br>Comma, Period, Hyphen, Slash, Corner brackets,<br></br>Parentheses, Yen sign |
| Space（full-width）             | Please enter full-width spaces                                                                                          |

> ❗️ Notes
>
> - Please enter in full-width characters
> - You can enter up to 30 full-width characters (dakuten and handakuten each count as one character)
> - Kanji cannot be used
> - Middle dot（・）cannot be used  
>   If a middle dot（・）is present, replace it with a period（．）

The following abbreviations are allowed  
Input examples）  
〇〇株式会社　　　　　　→　〇〇（カ  
株式会社〇〇　　　　　　→　カ）〇〇  
〇〇株式会社 東京営業所   →　〇〇（カ）トウキョウ（エイ
