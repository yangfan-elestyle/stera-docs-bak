---
title: 账户名可输入哪些字符？
---

对于您在申请表中输入的账户名，可使用的字符如下

请先确认正确的“账户名”，并在“账户名（片假名）”中输入

| 类型                 | 可使用的字符                                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 片假名（全角）       | アイウエオ　カキクケコ　サシスセソ　タチツテト　ナニヌネノ<br></br>ハヒフヘホ　マミムメモ　ヤユヨ　ラリルレロ　ワヲン |
| 假名+浊点（全角）    | ガギグゲゴ　ザジズゼゾ　ダヂヅデド　バビブベボ　ヴ                                                                    |
| 假名+半浊点（全角）  | パピプペポ                                                                                                            |
| 数字（全角）         | ０１２３４５６７８９                                                                                                  |
| 英文字母（全角大写） | ＡＢＣＤＥＦＧＨＩＪＫＬＭＮＯＰＱＲＳＴＵＶＷＸＹＺ                                                                  |
| 符号（全角）         | ，　．　－　／　「　」　（　）　￥<br></br>逗号、句号、连字符、斜杠、引号括号（「」）、<br></br>圆括号、日元符号      |
| 空格（全角）         | 请输入全角空格                                                                                                        |

> ❗️ 注意
>
> - 请使用全角字符输入
> - 最多可输入全角30个字符（浊点、半浊点各计为1个字符）
> - 不可使用汉字
> - 不可使用中点（・）  
>   如存在中点（・），请替换为句号（．）

另外，可使用的简称如下  
输入示例）  
〇〇株式会社　　　　　　→　〇〇（カ  
株式会社〇〇　　　　　　→　カ）〇〇  
〇〇株式会社 東京営業所   →　〇〇（カ）トウキョウ（エイ
