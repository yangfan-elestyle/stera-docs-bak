使用 <EText name="elepay" /> 的 Customer（客户）功能，可以创建客户以支持周期性扣款，或使用已登记的支付方式进行支付。Customer 功能需要同时配合 Client SDK 与 API 使用。

# 使用 API 创建客户

## 1. 登记支付方式

用户在移动应用或网页中登记支付方式。

## 2. 创建客户

您的服务端调用 [创建 Customer](/openapi/customer/createCustomer) 接口，创建与用户关联的客户。如需登记多种支付方式，请复用既有客户。

## 3. 创建 Source 对象

您的服务端调用 [创建 Source](/openapi/customer/createSource) 接口，生成 Source 对象。

## 4. 传递 Source 对象

您的服务端将 <EText name="elepay" /> 返回的 Source 对象传递给客户端的 Client SDK。

## 5. 登记（预授权）

客户端的 Client SDK 使用 Source 对象执行登记（预授权）流程。

## 6. 登记（预授权）结果

流程完成后，所选支付渠道的服务器会返回结果。

## 7. 接收 Webhook 事件

若登记成功，<EText name="elepay" /> 会向 Webhook 配置的 URL 发送事件通知。

## 8. 发起周期性扣款

使用 `CustomerId` 与 `SourceId`，您的服务端可调用 [创建 Charge](/openapi/charge/createCharge) 接口进行扣款。
