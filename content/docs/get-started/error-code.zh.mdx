本文说明 <EText name="elepay" /> 中可能出现的错误代码。

## API 的 HTTP 状态码

通常会返回三类状态码。

| 代码    | 说明                                                      |
| ------- | --------------------------------------------------------- |
| **2xx** | **成功** 请求已成功受理                                   |
| **4xx** | **客户端错误** 客户端发送的请求有误。                     |
| **5xx** | **服务器错误** <EText name="elepay" /> 服务器处理请求失败 |
