在开始开发之前，请先了解 <EText name="elepay" /> 的开发环境。登录 <EText name="elepay" /> 管理后台即可配置下列环境。部分信息需要写入源代码，请勿对外公开。

# 测试模式与生产模式

<EText name="elepay" /> 为开发者提供 Test（测试）与
Live（生产）两个环境。开发时为每个环境配置对应的 App Key，即可在两者之间切换。

## 测试模式

使用测试环境需要先注册 <EText name="elepay" /> 账户。即使各支付方式仍处于审核中，您也可以在测试环境中推进开发。

## 生产模式

各支付方式开通后，即可在生产环境中发起真实支付。

# 获取并配置 Test Key 与 Live Key

Test/Live 环境的密钥在 <EText name="elepay" /> 管理后台维护。点击左侧“開発設定 / API”即可查看 API 密钥。
