title: 退款处理

<EText name="elepay" /> 也提供退款功能。您的服务端可以通过 API 发起退款。

# 通过 API 进行退款

## 1. 发起退款请求

您的服务端调用 [创建退款](/openapi/refund/createRefund) 接口以发起退款请求。

## 2. 处理返回值

<EText name="elepay" /> 服务器会返回一个 Refund 对象。
<br />
若请求已被正确接收，Refund 对象的 `failure_msg` 字段为 Null。

## 3. 接收 Webhook 事件

退款成功后，<EText name="elepay" /> 会向 Webhook 配置的 URL 发送 `refund.succeeded` 事件通知。

# 在管理后台中退款

可在“支払い管理 / 支払い一覧”中对指定的支付记录执行退款。

<EImg src="image.get-started.refunds.img2" />

> 📘 退款时效
>
> 退款时效为自创建收入（売上）之日起 90 天内。

> ❗️ 退款请求与已退款状态
>
> 退款为异步处理。即使发起了退款请求，状态也不一定会立即变为“已退款”。
