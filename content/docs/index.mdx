---
title: Elepay について
description: マルチモバイル決済サービス
---

elepay はモバイルに特化したマルチ決済プラットフォームです。複雑なモバイル決済処理を一本化し、一度の開発でメジャーなモバイル決済方法に対応できます。elepay SDK は Client SDK と Server SDK を含みます。Client SDK は iOS, Android と HTML 5 に対応しています。Server SDK は７種類のバックエンドの開発言語に対応しています。

# 特徴

## 簡単導入

- 一本化された SDK/API
- 開発者が使いやすい
- 簡単で効率的な導入
- 優れた API デザイン

## オールインワン

一度の開発でメジャーなモバイル決済方法に対応できます。今後も新たなモバイル決済方法にも対応する予定です。

| 地域       | 利用可能な決済ブランド                                                                                                                                    |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 日本       | PayPay、LINE Pay、楽天ペイ、au Pay、d 払い、Paidy、atone、AEON Pay                                                                                        |
| 中国大陸   | Alipay、WeChat Pay、UnionPay、雲閃付                                                                                                                      |
| アジア     | JKOPAY(台湾)、AlipayHK(香港)、KaKaoPay(韓国)、Touch'n Go(マレーシア)、GCash(フィリピン)、TrueMoney(タイ)、DANA(インドネシア)、Rabbit LINE Pay、Boost、BPI |
| グローバル | Apple Pay、Google Pay、Paypal、AmazonPay、クレジットカード (Visa、MasterCard、Amex、JCB、DinnersClub、Discover)                                           |

## コスト節約

- お得な決済手数料プランをご用意しています。
- 開発、導入、管理コストを最小限に抑えることができます。
- プライベート SaaS プランもご提供可能です。

# ターゲット

## スタートアップ支援

決済システムの開発、運用、管理のコストを最小限に抑えながら、サービスの利用を開始できます。

## EC サービス

インターネット上でものを売買する EC サービス事業主様にとっては、決済方法の少なさによる購買機会の損失を減らすことができます。

## インバウンド

外国でよく使われている Alipay、WechatPay、銀聯、Apple Pay、Google Pay、Paypal などのモバイル決済手段にも対応。訪日外国人による日本国内での消費活動に繋がるサービスに役立ちます。

## シェアリングエコノミー

シェアリングバイク、シェアリングバッテリ、シェアリング駐車場などのシェアリングエコノミーサービスに最適な決済ソリューションをご提供します。

## O2O サービス

インターネット上のサービス(Online)を、実店舗(Offline)での集客アップや購買促進につなげる QR コードソリューションをご提供します。
