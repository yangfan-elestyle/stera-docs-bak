## elepay Android SDK 如何支持 Google Play 的 16KB 要求？

elepay Android SDK 已经处理了 16KB 对齐问题，但仅 x86_64 架构的 APK 需要单独处理。由于市面上几乎没有 x86_64 真机，请参考以下方法排除 x86_64：

```kotlin
android {
    defaultConfig {
        ndk {
            abiFilters += listOf("arm64-v8a", "armeabi-v7a") // 删除 "x86_64"
        }
    }
}
```
