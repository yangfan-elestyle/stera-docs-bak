## elepay Android SDK 如何支持 Google Play 的 16KB 要求？

elepay Android SDK 已经处理了 16KB 对齐问题，但仅 x86_64 架构的 APK 需要单独处理。由于市面上几乎没有 x86_64 真机，请参考以下方法排除 x86_64：

```kotlin
android {
    defaultConfig {
        ndk {
            abiFilters += listOf("arm64-v8a", "armeabi-v7a") // 删除 "x86_64"
        }
    }
}
```

如果 app 依旧出现 Google Play 16KB 对齐问题，请参考以下流程，确认是否是 app 中其他三方依赖包的影响：

```
1. > ./gradlew :app:assembleDebug
// app 打包文件位于：app/build/outputs/apk/debug/xxx.apk

2. > check_elf_alignment.sh xxx.apk
// sh 脚本可通过 Google 官方获取：https://developer.android.com/guide/practices/page-sizes#elf-alignment
```
