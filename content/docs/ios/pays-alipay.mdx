Alipay は、アント・フィナンシャル社の iOS, Android や Web ブラウザで、簡単かつ安全に支払いができる決済サービスです。

# iOS 9 及び以降のシステムについて

Alipay アプリに遷移するために、Xcode の  **PROJECT** → **TARGETS**  にある  **Info**タグ（或いは  `Info.plist`）で、`LSApplicationQueriesSchemes` Key を追加してください。

```xml
<string>alipay</string>
```

# iOS App の Callback URL Scheme について

elepay デフォルト  *URL Scheme*  については、[こちら](https://developer.elepay.io/docs/ios-sdk#section-1-url-scheme-%E3%81%AE%E8%BF%BD%E5%8A%A0)をご参照ください。
