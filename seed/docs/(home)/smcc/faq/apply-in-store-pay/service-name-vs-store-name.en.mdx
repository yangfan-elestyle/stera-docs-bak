---
title: What is the difference between the service (trade) name and the store name?
---

The trade name refers to the name displayed on the store’s signboard. The store name is required when there are branch locations.

| Corporate name                             | Service name (trade name)                                                                                                                                                                                                                                                                                                               | Store name                                                                                                                                                                                                      |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ABC Corporation                            | XX (brand name)<br />XX Parking Service<br />XX Online Shop                                                                                                                                                                                                                                                                             | XX Azabu No.1 Parking<br />XX Shibuya Store                                                                                                                                                                     |
| Name of the corporation or sole proprietor | Name used for the business (brand name)                                                                                                                                                                                                                                                                                                 | Name of each store                                                                                                                                                                                              |
| This is the legal registered name.         | Because it appears at checkout and on the statement after payment, an appropriate name is required so users can easily identify which service they paid for.<br />We recommend a clear and concise service name.<br />If you have a brand name, please enter the brand name.<br />Important: Using the corporate name is not permitted. | For some payment methods, the store name may also be displayed separately from the service (trade) name.<br />If you have only one location, you may set the service name and the store name to the same value. |
