---
title: 服务名称（屋号）与店铺名称有何区别？
---

“屋号”是指张挂在店铺招牌上的名称。相对地，“店铺名称”是在存在分店时需要填写的信息。

| 法人名称               | 服务名称（屋号）                                                                                                                                                                             | 店铺名称                                                                                                                    |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| ABC 株式会社           | 〇〇（品牌名）<br />〇〇停车服务<br />〇〇线上商店                                                                                                                                           | 〇〇麻布第 1 停车场<br />〇〇涩谷店                                                                                         |
| 法人或个体工商户的名称 | 业务中使用的名称（品牌名）                                                                                                                                                                   | 各门店的名称                                                                                                                |
| 法律上的正式名称       | 由于会在支付时及支付完成后的账单明细中显示，为便于用户明确识别其支付对象，需要使用恰当的名称。<br />服务名称建议清晰、简洁。<br />如有品牌名，请填写品牌名。<br />重要：不允许使用法人名称。 | 在部分支付方式中，除服务名称（屋号）外，亦可能单独显示店铺名称。<br />若仅有 1 家门店，可将服务名称与店铺名称设为相同名称。 |
