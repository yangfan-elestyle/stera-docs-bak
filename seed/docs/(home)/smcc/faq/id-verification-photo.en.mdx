title: How to Photograph Your ID Document
---

Refer to the “Sample Photos” below and photograph your identity verification document using your smartphone/tablet’s camera.

### Sample Photos

![](/docs/0bb9a3b-image.png)

### Notes When Taking Photos

- Photograph the original ID document
- The ID document must be within its validity period
- The image must be in color
- The image must be clear and the text legible
- Include background so that all four corners of the ID document are visible
- Do not use any editing/beautification apps
- File format must be .png or .jpg

※Scanned copies are not accepted; always photograph the original using the camera app
