title: 入金・手数料について
---

入金・手数料計算方法について<br />デフォルトの入金開始金額は5,000円で、事務手数料は300円です。 決済手数料は、指定期間内の売上に基づき計算され、各決済方法ごとに算出します。小数点以下は、全決済方法の手数料を合計した後、四捨五入で処理されます。四捨五入された手数料からは消費税が算出されます。また、クレジットカードによる決済手数料は非課税対象となります。<br />包括契約の詳細<br />各決済会社との契約に必要な手続きは、すべてELESTYLE株式会社が代行します。したがって、加盟店様はELESTYLEとのみ契約することになります。また、elepay・OneQRの売上金の入金やその他の経理処理も、ELESTYLEを介することで加盟店様は一本化できます。

入金一覧に表示する決済会社について<br />ELESTYLE株式会社（コード決済）<br />クレジットカード以外の決済方法との包括契約<br />月末締め、翌月末最後の営業日に入金<br />デフォルトの入金開始金額は5,000円 （変更が必要な場合はお問い合わせください）<br />事務手数料は300円<br />ELESTYLE株式会社（クレジット）<br />各クレジットカードブランドとの包括契約<br />月末締め、翌月末入金 （基本的には休前日に入金。出金銀行の処理プロセスにより、稀に翌営業日入金となる場合もあります）<br />1円からの入金が可能 ・事務手数料は無料（キャンペーン中）<br />手数料の計算方法<br />ELESTYLE株式会社（コード決済）<br />指定期間内の売上を、決済方法ごとに手数料を計算します。<br />決済方法ごとの手数料① = (決済方法毎売上金額 - 決済方法毎返金金額) × 手数料率<br />決済手数料（総額）② ※1 = ①(PayPay) + ①(auPAY) + ①(d払い)...の合計<br />消費税③ ※2 = ② × 消費税率(例：10%)<br />振込金額 = 売上金額 - 返金金額 - ② - ③ - 事務手数料<br />※1 決済手数料の端数処理は「四捨五入」。例：3.5円 → 4円<br />※2 消費税の端数処理は「切り捨て」。例：3.5円 → 3円

ELESTYLE株式会社（クレジット）<br />トランザクションが成立するごとに手数料を計算します。決済が成立した後に返金が行われても、手数料は返却されません。<br />計算方法：<br />トランザクション毎決済手数料①※ = 売上金額 × 手数料率<br />決済手数料（総額）② = ①(注文A) + ①(注文B) + ①(注文C)...の合計<br />振込金額 = 売上金額 - 返金金額 - ②<br />※決済手数料の端数処理は「四捨五入」。例：3.5円 → 4円

※クレジットカードに関しては決済手数料が非課税項目となります

入金一覧の確認方法<br />「入金一覧」から、特定の入金を見つけるために必要な情報（例えば、決済会社、対象期間、ステータスなど）を確認できます。特定の入金詳細を見るには、その行をクリックします。

入金詳細の見え方（コード決済）<br />「入金一覧」リストから特定の入金をクリックして、「入金詳細」ページに移動します。ここで、入金に関連する各種詳細（例えば、決済方法、決済金額、返金金額、手数料、消費税など）を確認することができます。

入金詳細の確認方法（クレジットカード）<br />「入金一覧」リストから特定の入金をクリックして、「入金詳細」ページに移動します。ここで、入金に関連する各種詳細（例えば、決済金額、返金金額、手数料など）を確認することができます。
