---
title: 店舗追加マニュアル（決済モジュール）
---

１．管理画面にログインします。

２．【アプリ管理】から対象アプリの「決済モジュール」をクリックします。

![](/docs/30c53a7882079d1f5c8fd2be18c94c037099faae3ab18ec4013e9fc66cbc454d-image.png)

３．「ロケーション」＞「ロケーション追加」をクリックし、画面右上の「＋新規」をクリックします。

![](/docs/beb63761dcff4d6774ab200d50a0ea7f9d1f5043024a22455c821a4cc0f5e87d-image.png)

＜単一店舗追加の場合＞

４．店舗情報（店舗名や住所など）を入力します。

| 項目 | 入力内容 |
| --- | --- |
| 店舗名 | ご利用になる店舗名を入力 |
| 店舗郵便番号 | ご利用になる店舗の郵便番号を入力 |
| 店舗住所 | ご利用になる店舗の住所を入力 |
| 店舗電話番号 | ご利用になる店舗の電話番号を入力 |
| クレジット(VM)取扱区分情報 | ご契約のある取扱区分を選択 |

![](/docs/8cb911b38b24522c6ec84bfa3f66169e4cf5bab177cc7ae71eaf5b84d7d9e984-image.png)

５．JCB/AMEX/DINERSとご契約がある場合は、ボタンをクリックして項目を入力します。

![](/docs/f71abf7a6bfa69dd27084dfa03ff19479c23687225808d9cbb4f7fc790360c9d-image.png)

![](/docs/e84e4cbd8e2ce306c8c6e606d32c39d9d6ef4318c94ab2c8517284c03da162e8-image.png)

＜複数店舗追加の場合＞

４．「複数店舗」を選択し、テンプレートのダウンロードを行います。

![](/docs/ae85bc6915e0a4ada56ee846c299237f315ed1758d85bb9fb040971617574cd5-image.png)

５．記入したファイルのアップロードを行います。

![](/docs/586bea64eed1a21b9ee9c86738c28843b5f0d75ba6c1633d427e12ebc7d598db-image.png)

６．「次へ」をクリックし、入力内容を確認のうえ「提出」ボタンをクリックします。

７．店舗追加申請は完了となります。

※利用可能になった際は登録済のメールアドレス宛にご連絡いたします。
