---
title: About the Order Note Feature
---

The order note feature allows customers to add free‑form requests when placing an order.<br />
(For example, specific allergy information, ingredient changes, or timing of item delivery.)<br />
This information is sent to the store together with the order details.

## Merchant‑side settings for order notes

### 1. Click Marketplace.

![](/docs/01db8e4f-user_cropped_screenshot.jpeg)

### 2. Click to install "Order note".

![](/docs/f74c2cf6-ascreenshot.jpeg)

### 3. Configure the settings on this screen.

・Set as required: If enabled, customers must fill in the note field before confirming the order. Useful when specific information is mandatory.

・Multi‑line input: Provides a multi‑line text area instead of a single‑line field, allowing customers to enter more information.

![](/docs/e4115a87-user_cropped_screenshot.jpeg)

### 4. Configure the label and placeholder (the faint text shown before input), and the maximum input length displayed to customers.

・Label example: "Requests for the order"

・Placeholder example: "Please enter allergy information or any requests related to the order"

・Max input length: Restrict the maximum number of characters if necessary.

![](/docs/39e69f73-ascreenshot.jpeg)

### 5. Click "Save" to complete the store‑side configuration.

![](/docs/223a851d-ascreenshot.jpeg)

## User‑side input for order notes

### 6. Click "Pay" at the bottom right.

![](/docs/8a6bd171-user_cropped_screenshot.jpeg)

### 7. Enter any special notes in the order note field.

Information entered by customers is available to the store together with the order details.

![](/docs/0e59a5e0-user_cropped_screenshot.jpeg)
