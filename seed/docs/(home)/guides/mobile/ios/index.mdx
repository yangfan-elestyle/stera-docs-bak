**iOS SDK** は stera smart one を iOS アプリに導入するための SDK です。<br />このガイドでは、SDK を iOS アプリと連携する方法について詳しく説明します。

# 対応バージョン

- **iOS SDK 5.0**  からは、SDK が `ElepaySDK` と `RPay` / `Checkout` などの独立した Plugin に分割され、必要に応じて導入する形となりました。5.0.5 からは、SGP（ApplePay / CreditCard）の処理が追加されました。
- **iOS SDK 4.0** からは、iOS 11.0 のサポートが対象外となりました。また、Bitcodeのサポートも終了しました。
- **iOS SDK 3.0** からは、iOS 10.0 のサポート対象外になりました。
- **iOS SDK 2.x** は、iOS 10.0 以上と互換性があります。
- 開発環境：Xcode 11.0 以上をご使用ください。

# インストール方法

## 1. Cocoapod によるインストール

> 📘 iOS SDK 5.0 からは、SPM（Swift Package Manager）を利用してください。他のインテグレーション方式に関するご要望がございましたら、stera smart one チームまでお問い合わせください。

1. Podfile に `ElepaySDK` を追加します。<br />**ご注意：Cocoapods 1.10.0 以上をご利用ください。**

```ruby
# バージョンが2.2未満のElepaySDKはdynamic frameworks形式のみ対応しています
# 2.3からのstatic frameworks形式の導入も対応しました
#use_frameworks!

# From 2.0.0, the SDK renamed from ElePay to ElepaySDK

pod 'ElepaySDK', '~> 3.0'
```

2. 中国のペイメント（Alipay, WeChat Pay, Union Pay）を利用する場合のみ、`Elepay_ChinesePayments_Plugin` も追加します。

```ruby
# From 2.0.0, the SDK renamed from ElePay-ChinesePayments-Plugin to Elepay_ChinesePayments_Plugin

pod 'Elepay_ChinesePayments_Plugin', '~> 2.0'
```

3. Stripe を利用する、かつ SDK が 2.2.0 以上の場合のみ、`Stripe` を追加してください。<br />ご注意：SDK 2.x を利用する場合は、`pod 'Stripe', '~> 19.4.1'` で Stripe を追加してください。

```ruby
# Only ElepaySDK 3.0 and above supports Stripe 21.x
# Use "pod 'Stripe', '~> 19.4.1'" if you are using ElepaySDK 2.x

pod 'Stripe', '~> 22.0'
```

> 🚧 Stripe v23がiOS 12のサポートを停止したため、SDKではStripe v22までを設定してください。

4. PayPal を利用する、かつ SDK が 1.7.0 以降の場合のみ、`Braintree`を追加してください。<br />**ご注意：**&#x53;DK 4.0.0からはBraintreeのサポートが終了しました。PayPalを利用する場合は、SDK 3.xをご利用ください。

```ruby
pod 'Braintree'
```

5. `pod install` を実行します。

## 2. Swift Package Manager (SPM)によるインストール

> 📘 iOS SDK 5.0 からは、SPM（Swift Package Manager）を標準の配布方式として提供しております。他のインテグレーション方式に関するご要望がございましたら、stera smart one チームまでお問い合わせください。

**iOS SDK** は 3.1.1 から SPM に対応しました。<br />**iOS SDK Chinese Payments Plugin** は 2.0.2 から SPM に対応しました。

1. SPM に SDK を追加します。<br />こちらの URL をご利用ください：`https://github.com/elestyle/elepay-ios-sdk.git`<br />バージョンを指定する場合は、3.1.1 以降をご指定ください。

2. 中国のペイメント（Alipay, WeChat Pay, Union Pay）を利用する場合のみ、`Elepay_ChinesePayments_Plugin` も追加します。<br />こちらの URL をご利用ください：` https://github.com/elestyle/elepay-ios-sdk-chinesepayments-plugin.git`<br />バージョンを指定する場合は、2.0.2 以降をご指定ください。

3. Stripe を利用する場合は、`Stripe` を追加してください。<br />こちらの URL をご利用ください：`https://github.com/stripe/stripe-ios.git`<br />バージョンを指定する場合は、21.8.1 以降をご指定ください。

4. PayPal を利用する場合は、`Braintree` を追加してください。<br />ご注意：`Braintree` の最新版 5.x.x は iOS 11 の対応が終了したため、4.x.x をご利用ください。また、4.x.x は SPM に対応していないため、Cocoapods で導入するか、手動でインストールしてください。

## 3. 手動インストール

7ステップで、SDK for iOS をアプリに導入できます。

1. [Github.com](https://github.com/elestyle/elepay-ios-sdk) で [`ElePaySDK.zip`](https://github.com/elestyle/elepay-ios-sdk/archive/master.zip) をダウンロードして解凍します。

2. `ElePay.framework` を Xcode のプロジェクトに追加します。必要に応じて「Copy items if needed」をチェックしてください。

3. ターゲット設定に、`ElePay.framework` を「Embedded Binaries」に追加します。

4. Objective-C のプロジェクトで Apple Pay を利用する場合、ターゲット設定に `PassKit.framework` を「Embedded Binaries」に追加する必要があります。

## 4. Objective-C プロジェクトで利用する場合

> 📘 Objective-Cで開発する場合
>
> Objective-C のプロジェクトに SDK を実装する場合、こちらの<br />[ElePayObjCBridge.swift](https://github.com/elestyle/elepay-ios-demo-swift/blob/master/ELEPayObjectiveC/ElePayObjCBridge.swift) ファイルをご利用ください。

Xcode で、**PROJECT** ＞ **TARGETS** 項目＞ **Info** タグにある **URL Types** を開いて、専用 _URL Scheme_ を追加してください。

### stera smart one共通の設定

stera smart one 専用の URL Scheme の取得方法は「[iOS / Android SDK用URL Schemeの取得](/guides/mobile/url-scheme)」へご参照ください。

![](/docs/96b54e2-ELEPayExample_xcodeproj.jpg "ELEPayExample_xcodeproj.jpg")

### URL Scheme のテスト

モバイル Safari や Chrome のアドレスバーに上記の _URL Scheme_（例：`ep1a2b3c4d5e://`）が正しく App を呼び出されるかどうかをテストできます。

> 📘 重要
>
> 複数の **TARGETS** が存在する場合、全てのターゲットの _URL Type_ に、上記の _URL Scheme_ を追加してください。

## 2. 各支払方法の設定に関して

[決済方法](/guides/mobile/payment-methods-config)ページをご参考ください。

## 3. stera smart one の初期化

プロジェクトの `application(_:didFinishLaunchingWithOptions:)` 関数に、以下の初期化コードを追加します。

```swift
Elepay.initApp(key: "ELEPAY_APP_PUBLIC_KEY")
```

> 📘 Public Key について
>
> `ELEPAY_APP_PUBLIC_KEY` を[「stera smart one 管理画面」](https://dashboard.sterasmartone.com)で発行したものに変更してください

## 4. callback の設定

`application(_:open:options:) -> Bool` 関数に, 以下のコードを追加します。

```swift
func application(_ app: UIApplication, open url: URL, options: [UIApplicationOpenURLOptionsKey : Any] = [:]) -> Bool {
    // Let elepay Handle Result Callback from 3rd party payment Apps first.
    if (Elepay.handleOpenURL(url)) {
        // When ELEPay has already handled the URL, make sure your code returns here.
        return true;
    }

    // for no payment URL handle it in your own code here.
    return false;
}
```

## 5. 支払い処理（都度決済）

### お客様サーバー側処理

**API** のチャージ API  `/api/charges` で都度決済を開始します。<br />当 API は認証が必要なため、認証用のセキュリティーキーを契約者が管理しているサーバーに保存して、そのサーバーから請求してください。

> ❗️ セキュリティー：
>
> 安全のために、セキュリティーキーは**絶対に**アプリに保存したり、転送したりしないでください。

### ネーティブApp側処理

**API** のチャージ API から取得したペイロードを、以下のコードのように **SDK** に送信して、**SDK** からのコールバックに支払い完了（失敗）後の処理コードを追加します。

以下３つの中で使いやすいメソッドをご利用ください。

#### 1. JSON String でチャージする場合：

```swift
_ = Elepay.handlePayment(
  chargeJSON: jsonString, 
  cardParams: elepayCardParams, /* <- Optinal parameter, can be removed */
  viewController: viewController) { result in
    switch (result) {
    case let .succeeded(paymentId):
        // your code for handling successful situation
    case let .canceled(paymentId):
        // your code for handling canceled by user
    case let .failed(paymentId, error):
        // your code for handling failure situation
    }
}
```

| パラメータ名         | 説明                                                                                   |
| :------------- | :----------------------------------------------------------------------------------- |
| chargeJSON     | ペイメントデータが含まれた `String` 型のJSON オブジェクトとなります。サーバー側により作成され、**iOS SDK** はこのデータで決済処理を行います。 |
| cardParams     | クレジットカードのUIをコントロールするオプショナルパラメータです。デフォルトは `nil` です。`nil` の場合、SDK内部のクレジットカードUIが使われます。  |
| viewController | 決済を行う際にUIを表示するために使われた `UIViewController` の実例となります。                                   |
| completion     | 決済の結果を通知するコールバックです。                                                                  |

## エラー処理

SDKが各種類のエラー（Error）がコールバックします。

ユーザー体験がよくなるため、`case unsupportedPaymentMethod(errorCode: String, paymentMethod: String)`のエラー情報をユーザーに表示する事をお薦めします。

サンプルコード

```swift
switch (result) {
case .succeeded(let codeId):
    // checkout is succeeded.
case .cancelled(let codeId):
    // checkout is canceled.
case let .failed(let codeId, let error):
    switch error {
    case let .unsupportedPaymentMethod(errorCode, method):
        if errorCode == "10110" {   // 3rd party App not installed error
            print("The \(method) App is not installed for payment processing. Please install the app first or selected another payment method.")
        } if errorCode == "10100" {   // The device or the iOS system is too old to use this payment method
            print("Your device is too old to use \(method)")
        } else {    // Other error codes. Such as: a new payment method not supported by current SDK. The App using elepay SDK need to be updated
            print("Your App need to be updated to use \(method)")
        }
    default:
        // other error handling code
    }
}
```

[エラーコード](/get-started/error-code) にエラーコードリストをご参照ください。

## 注意事項

> 🚧 支払い結果の処理について
>
> アプリ内の支払い結果は、ユーザーへの結果照会のみでご使用ください。実際の課金結果は必ずサーバー上の callback API を経由し、stera smart one サーバーから送信されたデータでご確認ください。 _詳しくは API ガイドをご確認ください。_

## 1. Apple Pay について

1. Apple Pay を実装するときは、Xcode の **PROJECT** → **TARGETS** にある **Capabilities** タグをクリックして、Apple Pay を「ON」に設定してください。

![](/docs/159aef2-3d0b638-ELEPayExample_xcodeproj.jpg "3d0b638-ELEPayExample_xcodeproj.jpg")

2. Apple Pay の証明書を[「stera smart one 管理画面」-「開発設定」-「Apple Pay」](https://dashboard.sterasmartone.com)にアップロードしてください。<br />証明書の作成方法は[こちらのドキュメント](/guides/mobile/payment-methods-config#apple-pay)でご参照ください。

## 2. LSApplicationQueriesSchemes（iOS 9 及び以降のシステム）について

各決済アプリに遷移するために、Xcode の **PROJECT** → **TARGETS** にある **Info**タグ（或いは `Info.plist`）で、`LSApplicationQueriesSchemes` Key を追加してください。

```xml
<key>LSApplicationQueriesSchemes</key>
	<array>
	    <string>**各アプリのSchemeを追加してください**</string>
	</array>
```

# 多言語

**iOS SDK** は多言語に対応しています（現状は English, Japanese, Simplified Chinese, Traditional Chinese に対応しています）。

SDK のデフォルトは iOS のシステム設定と一致した言語を表示します。

## 表示言語の指定

システム設定値と異なる言語を表示したい場合、以下のコードで表示したい言語を指定してください。

```swift
ElepayLocalization.shared.switchLanguage(code: .ja)	// Use Japanese

ElepayLocalization.shared.switchLanguage(code: .en)	// Use English

ElepayLocalization.shared.switchLanguage(code: .cn)	// Use Simplified Chinese

ElepayLocalization.shared.switchLanguage(code: .tw)	// Use Traditional Chinese
```

この `switchLanguage` 関数は何回でも使えます。関数を呼び出した後に表示される画面が指定した言語で表示します。

> 📘 一部の画面の表示言語がご指定出来かねます
>
> 一部の決済方法は第三者画面に遷移する事があります。その画面は SDK の制御範囲外のため、ご指定の言語と異なる言語で表示する可能性があります。
